# 🎵 Sound-Reactive RGB LED & Speaker from Upcycled HDD

Welcome to the GitHub repository for my DIY project where I turned a dead Hard Disk Drive (HDD) into a custom sound-reactive speaker with a dynamic RGB light show! 💡✨

## 🛠️ About The Project
In this project, I upcycled e-waste into a functional piece of tech art powered by a standard 12V input. The build combines Arduino programming with hardware modification, creating a synchronized light display that reacts to ambient sound/music using a microphone module and NeoPixel LEDs.

You can watch the full step-by-step process—from modifying the HDD mechanism to wiring the custom LED setup and audio amplifier—on my YouTube channel: **[Electron_DIY](https://www.youtube.com/@electrondiy)**.

---

## ⚙️ Hardware & Components Used (12V Input)

* **Microcontroller:** Arduino Nano
* **Motor Control:** DC 7V-12V Brushless Motor Driver
* **Lighting:** WS2812 16-bit Ring & 8-bit Strip RGB LEDs
* **Power Management:** LM2596 Voltage Regulator (Step-down)
* **Audio Reactivity:** FC-04 Sound Sensor Module
* **Audio Output:** JZ-B5W2 Audio Amplifier

---

## 💻 Arduino Code
The code in this repository manages the NeoPixel animations (rainbow waves, fading tails) and dynamically adjusts brightness based on real-time microphone input from the FC-04 module.
